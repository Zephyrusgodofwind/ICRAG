# Attribution

IrishClinicalRAG is an independently structured implementation created for this
repository. No source code from `yolo-hyl/medical-rag` is currently included.

That MIT-licensed project was named in the project charter as an architectural
reference for ideas including hybrid retrieval, ingestion pipelines, evaluation,
and API separation. If code is incorporated later, its copyright and MIT notices
must be preserved here and in the relevant files.

Clinical source documents remain the property of their publishers. The local
manifest records the authoritative source URL and acquisition metadata. Source
documents are not committed to Git by default.
